# Project Task Breakdown

## Phase 1: Planning

* Understand requirements.
* Identify functional requirements.
* Identify non-functional requirements.
* Identify assumptions and edge cases.
* Design the Medallion Architecture.
* Define the data model.

## Phase 2: Data Generation

* Generate customers data.
* Generate products data.
* Generate orders data.
* Introduce intentional quality issues.
* Validate generated row counts.

## Phase 3: Bronze Layer

* Create database setup.
* Create Bronze ingestion scripts.
* Ingest customers.
* Ingest orders.
* Ingest products.
* Validate ingestion counts.

## Phase 4: Silver Layer

* Implement completeness checks.
* Implement uniqueness checks.
* Implement type validation.
* Implement referential integrity checks.
* Implement business logic checks.
* Generate quality metrics.

## Phase 5: Gold Layer

* Create sales by product aggregation.
* Create revenue by customer aggregation.
* Create customer segmentation.
* Create sales trends aggregation.
* Validate calculations.

## Phase 6: Testing

* Create data quality tests.
* Verify intentional issues are detected.
* Perform pipeline validation.
* Record test results.

## Phase 7: Dashboard

* Write dashboard SQL queries.
* Create product revenue visualization.
* Create customer revenue distribution visualization.
* Create customer segmentation visualization.

## Phase 8: Documentation

* Complete README.
* Document AI prompts.
* Document debugging.
* Document testing.
* Complete reflection.
* Complete AI usage summary.
